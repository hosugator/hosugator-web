## Context
align-ai `train.py` 코드 리뷰 중 역전파를 처음 제대로 이해했다. "모델이 어느 가중치를 얼마나 바꿔야 loss가 줄어드는지 어떻게 아는가?" — 실제로 바꿔보는 건지, 아니면 다른 방법이 있는지 궁금했다.

## Insight
### 역전파는 랜덤 탐색이 아니라 미분으로 방향을 계산한다

Loss 함수는 수학적으로 미분 가능한 구조로 설계되어 있다. 각 가중치에 대한 편미분(기울기)을 구하면 "이 가중치를 늘렸을 때 loss가 증가하는가, 감소하는가"를 실제로 바꿔보지 않고 알 수 있다.

```
dLoss/dw > 0  →  w를 늘리면 loss 증가  →  w를 줄인다
dLoss/dw < 0  →  w를 늘리면 loss 감소  →  w를 늘린다

w_new = w - lr × (dLoss/dw)
```

### 연쇄 법칙(chain rule)이 다층 신경망을 가능하게 한다

순전파 시 각 층의 출력값이 저장된다. 역전파는 이 저장된 값들로 Loss에서 입력 방향으로 기울기를 층마다 계산한다. PyTorch는 `.backward()` 호출 시 이를 자동으로 처리한다.

### 기울기는 배치마다 초기화하고 가중치는 누적된다

`optimizer.zero_grad()`로 배치마다 기울기를 초기화하는 것이 맞다. 이전 배치의 학습 결과는 이미 가중치에 반영되어 있으므로, 기울기는 현재 위치에서 방향을 재측정하는 용도로만 쓰인다.

### Loss 함수는 전체 네트워크에 하나다

각 층은 `z = W·input + b`, `a = activation(z)`를 계산할 뿐이다. Loss는 최종 출력에서 정답과 비교해 한 번만 계산된다. 각 층에서 계산되는 건 "이 층의 가중치가 그 Loss에 얼마나 기여했는가"라는 편미분값(기울기)이지, Loss 자체가 아니다.

### .backward()와 .step()은 의도적으로 분리되어 있다

역전파는 두 단계로 분리된다.

1. `.backward()` — 출력층부터 입력층까지 모든 가중치의 기울기를 계산. 이 단계에서 가중치를 건드리지 않는다.
2. `.step()` — 모든 기울기 계산이 끝난 후 전 층의 가중치를 일괄 업데이트.

분리하는 이유: 기울기 계산 도중 가중치를 바꾸면, 다음 층의 기울기 계산에 "원래 순전파 값"이 아닌 "변형된 값"이 쓰여 chain rule이 틀어진다.

### 역전파가 순차적인 이유는 값 변경이 아니라 기울기 의존성이다

순전파는 "이전 층의 출력이 다음 층의 입력"이어서 순차적이다. 역전파는 가중치를 건드리지 않는데도 순차적이어야 한다. 이유가 다르다.

```
dL/dW2 계산 → dL/da1 이 부산물로 나옴
dL/dW1 계산 → dL/da1 이 필요 (앞 단계 결과)
```

각 층의 기울기가 다음 층 기울기 계산의 입력값이 되기 때문에, 출력→입력 방향의 순서가 강제된다.

### 역전파 시 "모르는 변수"는 없다

순전파에서 `a1, a2, z1, z2` 등 모든 중간값을 저장해뒀기 때문에, 역전파 시점에는 기호가 아닌 구체적인 숫자로 계산한다. `dL/da2 = 0.6`이라는 값은 그 자체로 완결된 의미("a2가 1 변할 때 Loss가 0.6 변한다")를 갖는다. a1이 뭔지 몰라도 이 문장은 참이며, 이 값이 다음 단계의 입력이 된다.

### ReLU의 미분은 0 또는 1이다

```
ReLU(z) = z  (z > 0),  0  (z ≤ 0)
da/dz   = 1  (z > 0),  0  (z ≤ 0)
```

z ≤ 0인 뉴런은 기울기가 0이 되어 그 뒤 층으로 기울기가 전달되지 않는다. 이를 dying ReLU 문제라 한다.

### 기울기는 가중치와 같은 shape의 텐서로 존재한다

기울기는 층마다 하나가 아니라 **가중치마다 하나**씩 존재한다. PyTorch에서 각 파라미터는 `.grad` 속성에 동일한 shape의 기울기 텐서를 갖는다.

```python
layer.weight        # shape: (128, 64)
layer.weight.grad   # shape: (128, 64)  ← 가중치마다 기울기 하나
```

`zero_grad()`는 이 `.grad` 텐서들을 전부 0으로 채우는 것이고, `backward()`는 계산해서 채우는 것이다.

### 편향도 가중치와 함께 업데이트된다

뉴런의 계산은 `z = W·x + b`이며, `b`(편향)도 학습 가능한 파라미터다. `model.parameters()`가 가중치와 편향을 모두 포함해 반환하므로 `optimizer.step()`이 둘 다 한 번에 업데이트한다. 설명에서 "가중치"라고 할 때는 편향을 포함한 모든 학습 파라미터를 통칭하는 경우가 많다.
