## Context
Docker 이미지와 ONNX 파일의 추출 가능성을 논하다가, 소스코드 보호의 실질적 의미와 AI 시대 진짜 자산이 무엇인지로 확장된 논의.
Docker 이미지는 레이어 단위 tar 파일이라 암호화 없이 완전 추출 가능. ONNX는 protobuf라 가중치와 계산 그래프를 그대로 읽을 수 있지만 원본 학습 코드는 복원 불가.
이 사실에서 "소스코드가 이미지 안에 있으면 위험하다"는 전제 자체를 재검토하게 됐다.

## Insight
### 하락한 것은 코드 생성 비용이지 코드의 가치가 아니다
CLI AI 등장으로 "코드를 타이핑하는 노동의 희소성"이 낮아진 것이다. 하락하지 않은 것:
- 무엇을 만들어야 하는지 아는 도메인 판단
- 생성된 코드가 맞는지 검증하는 능력
- 시스템 전체에서 어떤 위치에 무엇이 필요한지 설계하는 것

### 가중치의 가치는 세 층으로 구성된다
- 재현 비용: 같은 가중치를 만들려면 동일한 데이터 + compute + 시간이 필요하다.
- 데이터 비가역성: 학습 데이터를 다시 모을 수 없는 경우가 많다. 가중치는 그 데이터의 압축된 표현이다. 데이터가 사라져도 가중치는 남는다.
- 암묵지 결정화: 하이퍼파라미터 튜닝, 데이터 정제 판단, 실패한 실험들이 숫자 안에 응축되어 있다.

### 도메인 특화 소형 모델의 실질 자산은 데이터 희소성이다
LLM처럼 compute 자체가 진입장벽인 경우를 제외하면, 작은 도메인 특화 모델의 가치는 거의 전적으로 학습 데이터의 희소성에서 온다.

| 모델 유형              | 실질 자산                              |
| ------------------ | ---------------------------------- |
| LLM급               | compute 규모 + 데이터 규모 (재현 비용 자체가 장벽) |
| 도메인 특화 소형 모델       | 현장에서만 나오는 데이터                      |
| 공개 데이터 fine-tuning | 거의 없음 — 누구나 재현 가능                  |
### AI 시대 진짜 해자는 현장 데이터 파이프라인과 도메인 판단력이다
코드 작성 능력 → 범용화됨
모델 아키텍처 지식 → 빠르게 범용화 중
현장 데이터 수집 파이프라인 → 여전히 희소
데이터가 뭘 의미하는지 아는 도메인 판단 → 더 희소

DTK 맥락에서: Corning 렌즈 불량 패턴을 볼 수 있는 현장 위치 자체가 자산이다. 모델은 그 위치를 활용하는 도구.
