## 핵심 원칙

타겟 도메인에 **레이블이 없을 때**, 소스에서 학습한 모델을 타겟에서도 동작하게 만드는 기법.  
가중치를 정답 피드백으로 수정하는 게 아니라, **두 도메인의 특징 분포를 서로 가깝게 정렬**한다.

---

## 분포(Distribution)란 정확히 무엇인가

데이터 값들이 어떤 패턴으로 퍼져 있는지 — **히스토그램의 모양**이다.

```
소스 (낮 공장 이미지) 밝기 분포:
  어둠 ░░▒▒▓▓████████▓▓▒░ 밝음
  → 중간~밝은 값에 데이터가 집중

타겟 (야간 공장 이미지) 밝기 분포:
  어둠 ███████▓▓▒░░░░░░░░ 밝음
  → 어두운 값에 데이터가 집중
```

"두 분포가 다르다" = 두 히스토그램의 모양이 다르다는 뜻이다.  
모델은 소스 히스토그램 패턴에서 학습했기 때문에, 모양이 다른 타겟에서 오작동한다.

<!-- 💡 밝기(1차원) 외에도 색조, 텍스처, 노이즈 수준 등 수백 차원의 분포가 동시에 다를 수 있다. 딥러닝에서 "분포"는 이 고차원 패턴 전체를 가리킨다. -->

---

## 왜 그냥 Fine-Tuning을 안 하나

```
Fine-Tuning의 전제: "타겟 데이터 + 정답 레이블이 있다"
                         ↑
Domain Adaptation의 상황: 레이블이 없다!
```

공장 야간 이미지가 수천 장 있어도, 어느 게 불량이고 어느 게 정상인지  
**사람이 일일이 태깅하는 비용이 너무 크거나 불가능할 때** Domain Adaptation이 필요하다.

---

## 작동 방식 1: 통계적 정렬 (Statistical Alignment)

소스 특징 벡터와 타겟 특징 벡터의 **통계(평균, 분산)를 수학적으로 가깝게** 만든다.

```
소스 특징 벡터 통계: 평균=[0.8, 0.2, ...], 분산=[0.1, 0.3, ...]
타겟 특징 벡터 통계: 평균=[0.3, 0.7, ...], 분산=[0.4, 0.1, ...]
                            ↓
                   두 통계의 차이를 최소화하도록 변환
                            ↓
소스 특징 ≈ 타겟 특징  (분포가 정렬됨)
```

- 대표 기법: **CORAL** (Correlation Alignment) — 공분산 행렬의 차이를 최소화
- 레이블 없이 통계만으로 작동한다.

---

## 작동 방식 2: 적대적 정렬 (Adversarial Alignment, DANN)

**"소스인지 타겟인지 구분할 수 없는 특징"** 을 만들도록 학습한다.

```
[특징 추출기]
      │
      ├──→ [클래스 분류기]   "이 이미지가 불량인가?" (소스 레이블로 학습)
      │
      └──→ [도메인 판별기]   "이 특징이 소스인가 타겟인가?"
                                        ↑
                       특징 추출기는 이 판별기를 최대한 "헷갈리게" 만들도록 학습
```

두 가지를 동시에 학습한다:
1. 클래스 판별은 잘 해야 한다 (불량 감지 성능 유지)
2. 도메인 판별은 못 해야 한다 (소스/타겟 구분 불가능한 특징)

결과적으로 모델은 **"어느 도메인에서 왔는지 관계없이" 동작하는 특징**을 학습한다.

## 가중치는 어떻게 바뀌는가

Fine-Tuning과 Domain Adaptation 모두 역전파(backpropagation)로 가중치를 업데이트하지만, 피드백의 출처가 다르다.

| | 피드백 출처 | 타겟 레이블 필요 |
|-|-----------|----------------|
| **Fine-Tuning** | 타겟 정답 레이블의 오차 | 있어야 함 |
| **Domain Adaptation** | 분포 정렬 오차 (통계 차이 or 도메인 판별 오차) | 없어도 됨 |

---

## 실무 사례

- 낮 공장 이미지(소스, 레이블 있음) → 야간 이미지(타겟, 레이블 없음)
- 한 라인의 불량 데이터(소스) → 신규 라인(타겟, 재태깅 비용 큼)
- 합성 이미지(소스, 레이블 생성 쉬움) → 실제 이미지(타겟)
