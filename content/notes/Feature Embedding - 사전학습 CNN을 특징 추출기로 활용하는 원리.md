## 핵심 개념

사전학습된 CNN의 가중치를 고정(frozen)한 채, 중간 레이어 출력을 특징 벡터로 추출하는 기법.  
모델을 "분류기"가 아닌 "이미지 → 숫자 배열 변환기"로 활용하는 것이 핵심이다.

---

## 구성 요소 정의

### ImageNet
120만 장 이상의 이미지에 1,000개 카테고리 라벨이 붙은 공개 데이터셋.  
알고리즘이 아니라 **데이터셋**이다. "ImageNet으로 학습시킨다" = 이 데이터로 CNN을 사전훈련한다는 뜻.

### CNN (Convolutional Neural Network)
이미지 처리에 특화된 신경망 구조.  
픽셀 배열을 입력받아 계층적으로 패턴을 학습한다:
```
픽셀 → 가장자리(Edge) → 질감(Texture) → 형태(Shape) → 물체(Object)
```

### ResNet
CNN의 구체적 아키텍처 중 하나. Skip Connection(잔차 연결)으로 깊은 레이어에서도 학습 안정성을 확보한 구조.  
ImageNet 사전학습을 통해 일반 시각 패턴(색상, 질감, 윤곽선 등)을 이미 내재하고 있다.

### 특징 추출기(Feature Extractor)로 사용한다
ResNet의 최종 분류 레이어(softmax → 1,000 클래스)를 제거하고,  
그 직전 레이어의 출력 벡터만 꺼내 쓴다.

```
이미지 픽셀 → [Pre-trained ResNet (frozen)] → Feature 벡터 (512차원)
                                                ↑ 여기서 출력을 꺼낸다
                                      (분류 레이어는 사용하지 않음)
```

### 가중치 고정(Frozen Weights)
ResNet의 학습된 파라미터를 변경하지 않는다.  
도메인 특화 이미지(렌즈, 회로기판 등)로 별도 재학습 없이 그대로 활용 가능.  
ImageNet의 일반 시각 패턴이 도메인에 무관하게 유의미한 특징을 추출한다는 실험적 전제에 기반.

---

## 왜 이것이 도메인을 넘어 동작하는가

CNN의 레이어는 계층별로 다른 수준의 특징을 학습한다.

| 레이어 구간 | 학습 내용 | 물리적 근거 | 도메인 이식성 |
|------------|---------|-----------|------------|
| 저수준 (1~3층) | 엣지, 기울기, 색상 경계 | 밝기 불연속 = 경계 (물리 법칙) | 매우 높음 |
| 중수준 (4~7층) | 질감(texture), 반복 패턴, 곡률 | 재료 고유 광학 특성 | 높음 |
| 고수준 (8~N층) | 물체 형태, 의미적 개념 | 특정 학습 도메인 종속 | 낮음 |

저수준·중수준 특징이 도메인 무관하게 이식되는 이유:  
이미지라는 매체 자체가 가진 물리 법칙(밝기 불연속 = 경계, 주기적 변화 = 질감)에서 나오기 때문이다.  
특정 이미지를 외우는 것이 아니라 시각 구조의 보편 문법을 학습하는 것이다.

### 조명 민감도

조명 조건이 달라지면 레이어별로 영향이 다르게 나타난다.

| 레이어 | 조명 민감도 | 이유 |
|--------|------------|------|
| 저수준 (엣지) | 낮음 | 상대적 밝기 차이로 작동 |
| 중수준 (질감) | 중간 | 절대 밝기 의존 패턴 포함 |
| 고수준 (의미) | 높음 | 색상·밝기 분포가 바뀌면 혼란 |

조명이 크게 달라지면 중수준 이상에서 **도메인 갭(domain gap)**이 발생한다.  
Feature Embedding을 안정적으로 사용하려면 조명 조건을 물리적으로 고정하거나, 전처리(CLAHE, 히스토그램 정규화)로 입력 이미지를 표준화해야 한다.

## 적용 맥락

이미지 기반 이상탐지 모델들(PatchCore, PaDiM, EfficientAD, FastFlow)은 방식은 달라도  
모두 이 Feature Embedding을 공통 기반으로 사용한다.

| 모델 | Feature 활용 방식 |
|------|-----------------|
| PatchCore | 패치별 Feature → 메모리 뱅크 저장 → KNN 거리 |
| PaDiM | 패치별 Feature → 다변량 가우시안 분포 추정 |
| EfficientAD | Teacher/Student의 Feature 출력 Gap |
| FastFlow | Feature → Normalizing Flow로 정규분포 변환 |
