## 핵심 개념

레이블을 개별 샘플이 아닌 샘플 묶음(가방, bag) 단위로 부여하고,  
추론은 가방 안의 개별 인스턴스(instance) 단위로 수행하는 학습 패러다임.

레이블 수집 비용이 크거나 세밀한 레이블링이 구조적으로 불가능할 때 적합하다.

---

## 반지도 학습과의 구분

MIL(Multiple Instance Learning)은 약지도 학습(Weakly Supervised Learning)의 하위 개념이다.

| | 반지도 학습 | MIL |
|--|:---|:---|
| 레이블 단위 | 일부 개별 샘플에 레이블 있음 | 가방(bag) 단위로만 레이블 |
| 무레이블 데이터 | 레이블 없는 샘플이 다수 | 인스턴스 개별 레이블이 없음 |
| 목적 | 무레이블 샘플까지 활용해 성능 향상 | 가방 레이블로 인스턴스 판별 능력 학습 |

---

## 구조

```
가방(Bag) = 금형 1회 사이클
  ├── 인스턴스 1 = 제품 #1
  ├── 인스턴스 2 = 제품 #2
  ├── ...
  └── 인스턴스 N = 제품 #N

레이블: 가방(금형) 단위 제공  →  "이 금형 사이클에 불량 있음/없음"
추론:   인스턴스(제품) 단위  →  "이 제품이 불량인가"
```

가방 레이블의 의미:
- 양성 가방(Positive Bag): 인스턴스 중 최소 1개가 양성(불량)
- 음성 가방(Negative Bag): 모든 인스턴스가 음성(정상)

모델은 "양성 가방에 적어도 하나의 양성 인스턴스가 있다"는 제약만 학습에 사용한다.

---

## 제조업 시계열에서의 적용 패턴

금형 단위로 공정 데이터를 받는 구조는 MIL의 전형적 사례다:

```
데이터 수집 단위:  금형 1사이클 (bag)
채점 단위:        금형 내 개별 제품 (instance)
레이블 출처:      최종 검사 결과 — 금형 단위 합부 판정
```

문제: 어느 제품(인스턴스)이 불량인지는 모른다. 금형 전체가 불량이었다는 것만 안다.  
MIL의 역할: 가방 레이블만으로 인스턴스 수준의 이상 점수를 도출한다.

---

## 실용적 고려사항

양성 가방 내 양성 인스턴스 비율이 낮을수록 학습이 어렵다.  
예: 금형 100개 제품 중 1개만 불량 → 어느 인스턴스가 불량인지 특정하기 매우 어려움.

완화 방법:
- Attention-based MIL: 각 인스턴스에 가중치(attention score)를 학습해 양성 인스턴스를 자동 식별
- 이상탐지(비지도)와 MIL 혼합: 비지도로 이상 후보를 좁힌 뒤 MIL로 판정

음성 가방의 품질이 중요하다.  
음성 가방의 모든 인스턴스는 확실히 정상이어야 한다 — 음성 가방에 미탐된 불량이 섞이면 학습 신호가 오염된다.
