# ML 아키텍처 개요 — 현업 모델 비교

## 1. 구조 축(Architecture)이란

ML 모델을 이해하는 핵심 관점은 **구조 축**이다. "데이터를 어떻게 읽는가"를 결정하며, 이후 태스크·학습방식은 그 위에 올라타는 레이어다.
구조 축 외에도 여러 관점이 있다:

| 축                    | 핵심 질문        | 예시                          |
| -------------------- | ------------ | --------------------------- |
| **구조(Architecture)** | 데이터를 어떻게 읽는가 | CNN, Transformer, SSM       |
| **태스크**              | 무엇을 출력하는가    | 분류, 검출, 세그멘테이션              |
| **학습 패러다임**          | 어떤 신호로 배우는가  | 지도/비지도/자기지도                 |
| **출력 성격**            | 판별 vs 생성     | Discriminative / Generative |
| **스케일**              | 모델 크기        | 경량/엣지 / Foundation Model    |

> 예: PatchCore = CNN 구조 + 이상탐지 태스크 + 비지도학습 패러다임 + Discriminative 출력

## 2. 구조 축의 역사 — 각 세대가 앞 세대의 병목을 해결했다
### FC → CNN: 파라미터 폭발 해결

FC(Fully Connected)는 뉴런마다 독립 가중치를 소유한다. 1000×1000 이미지에 뉴런 1000개면 가중치가 10억 개에 달한다.
CNN은 **하나의 커널을 레이어가 소유하고 모든 공간 위치가 공유**한다. 같은 엣지 감지 함수를 이미지 전체에 슬라이딩하므로 파라미터가 수천 배 줄어든다. 레이어를 쌓을수록 픽셀 → 엣지 → 질감 → 형태 → 객체 순으로 추상화된다.
**CNN이 이미지에 적합한 이유**: 엣지나 질감은 위치와 무관하게 동일한 방식으로 감지할 수 있다(위치 불변성).

### CNN → RNN: 시간 축 처리

CNN은 공간 데이터에 강하지만 순서가 있는 시퀀스(텍스트, 음성)에는 적합하지 않다. RNN은 고정 크기 은닉 상태 h에 과거 정보를 누적하며 토큰을 순차 처리한다.
한계: h가 고정 크기라 토큰이 늘어날수록 초기 정보가 희석된다. 또한 h_{t}를 계산하려면 h_{t-1}이 필요해서 병렬화가 불가능하다.

### RNN → Transformer: 병렬화 + 전역 참조

Transformer는 은닉 상태 대신 **Q·K 유사도로 모든 토큰 쌍의 관계를 한 번에 계산**한다(Self-Attention). 순차 처리 의존성이 없어 GPU 병렬화가 가능하다.
한계: 모든 토큰 쌍을 비교하므로 토큰 수 n에 대해 O(n²) 연산이 필요하다.

### Transformer → SSM: 긴 시퀀스 효율화

SSM은 RNN의 재귀 구조에서 비선형 함수를 제거해 **선형 점화식**으로 만든다. 선형 점화식은 수학적으로 전개 가능해서 병렬 학습이 가능하면서도, 추론 시에는 h 하나만 유지하면 된다(O(1) 메모리).

```
구조          학습      추론 메모리   장거리 기억
RNN           직렬      O(1)          약함
Transformer   병렬      O(n)          강함
SSM (Mamba)   병렬      O(1)          강함
```

### 각 구조 축의 설계 대상 데이터

| 구조          | 설계 대상       | 계산 단위         | 강점        |
| ----------- | ----------- | ------------- | --------- |
| FC          | 정형 벡터       | 뉴런 (전체 입력 참조) | 최종 분류 레이어 |
| CNN         | 이미지 (공간)    | 공간 위치 (국소 입력) | 위치 불변 패턴  |
| RNN         | 짧은 시퀀스      | 타임스텝          | 순서 있는 데이터 |
| Transformer | 시퀀스 (중간 길이) | 토큰 (전체 참조)    | 복잡한 관계 추론 |
| SSM         | 긴 시퀀스       | 토큰            | 메모리 효율    |

## 3. CV 현업 대표 방법론

### 분류 (Classification)

이미지 전체에 클래스 레이블 하나를 부여한다.
**필요 데이터**: 이미지 + 클래스 레이블

| 방법론          | 구조 축        | 특징                                  | 적합 상황       |
| ------------ | ----------- | ----------------------------------- | ----------- |
| ResNet       | CNN         | 잔차 연결로 깊은 네트워크 가능. 전이학습 backbone 표준 | 범용          |
| EfficientNet | CNN         | 크기·속도·정확도 균형. B4가 산업 검사 기본 베이스라인    | 엣지/저사양      |
| ViT          | Transformer | 이미지를 패치 토큰으로 처리. 데이터 많을수록 CNN 계열 앞섬 | 데이터 2,000장+ |

### 검출 (Object Detection)

객체의 위치(박스)와 클래스를 동시에 예측한다.
**필요 데이터**: 이미지 + 박스 레이블

| 방법론          | 구조 축        | 특징                          | 적합 상황         |
| ------------ | ----------- | --------------------------- | ------------- |
| YOLOv8       | CNN         | 1-stage. 실시간 추론 대표          | 빠른 프로토타입, 실시간 |
| RT-DETR      | Transformer | 앵커 없음. 소형 객체 강세. Apache 2.0 | 소형 결함 탐지      |
| Faster R-CNN | CNN         | 2-stage. 정확도 높지만 추론 느림      | 정확도 우선        |

> ⚠️ YOLOv8 라이선스: AGPL-3.0 — 상용 배포 시 소스코드 공개 의무 발생

### 세그멘테이션 (Segmentation)

픽셀 단위로 클래스를 분류한다. 검출보다 레이블 비용이 높다.
**필요 데이터**: 이미지 + 픽셀 단위 마스크 레이블

| 방법론         | 구조 축 | 태스크      | 특징                                 | 적합 상황      |
| ----------- | ---- | -------- | ---------------------------------- | ---------- |
| U-Net       | CNN  | Semantic | Encoder-Decoder + 스킵 연결. 소량 데이터 강세 | 의료·산업 이미지  |
| DeepLab v3+ | CNN  | Semantic | 넓은 수용 영역                           | 일반 씬 이해    |
| Mask R-CNN  | CNN  | Instance | 개체별 마스크. 검출 + 세그멘테이션 동시            | 개체 구분 필요 시 |

> **Semantic vs Instance**: Semantic은 같은 클래스를 하나로 처리, Instance는 개체별로 구분

### 이상 탐지 (Anomaly Detection)

정상 패턴만으로 학습 후 벗어난 영역을 이상으로 판정한다.
**필요 데이터**: 정상 이미지만 (레이블 불필요)

| 방법론       | 구조 축 | 특징                                          | 적합 상황          |
| --------- | ---- | ------------------------------------------- | -------------- |
| PatchCore | CNN  | frozen backbone + 메모리 뱅크 + KNN. MVTec 현업 표준 | 산업 결함 탐지 초기 도입 |
| PaDiM     | CNN  | 패치별 가우시안 분포 모델링                             | 텍스처 결함         |
| FastFlow  | CNN  | Normalizing Flow. 추론 빠름                     | 실시간 라인 검사      |

### Foundation Model

레이블 없이 텍스트 프롬프트만으로 동작하는 범용 모델이다.

| 방법론            | 구조 축        | 태스크              | 동작 방식              |
| -------------- | ----------- | ---------------- | ------------------ |
| CLIP           | Transformer | Zero-shot 분류     | "불량품" 텍스트만 입력 → 분류 |
| SAM            | Transformer | Zero-shot 세그멘테이션 | 클릭/박스 프롬프트 → 마스크   |
| Grounding DINO | Transformer | Open-set 검출      | "빨간 스크래치" 텍스트 → 박스 |

**엣지 환경 한계**:

| 방법론            | 추론 VRAM | 저사양 PC |
| -------------- | ------- | ------ |
| SAM            | ~4GB    | ✗      |
| Grounding DINO | ~3GB    | ✗      |
| CLIP (ViT-B)   | ~1GB    | ▲ 제한적  |
| MobileSAM      | ~200MB  | ✅      |

현실적 접근: 게이트웨이 서버 추론 후 결과만 설비 PC로 전달, 또는 경량화 변형(MobileSAM, NanoSAM) 활용.

## 4. 전망 — 2025-2026 주요 흐름
### MoE가 프론티어 모델의 기본값이 됐다

2025년 기준 주요 랩(Meta, Google, DeepSeek, Mistral) 모두 Sparse MoE를 채택했다. 전체 파라미터의 5~10%만 활성화하는 방식으로, 모델은 크되 연산은 효율적이다.

```
DeepSeek-V3: 671B 전체 / 37B 활성 (~5.5%)
Llama 4:     400B 전체 / 17B 활성 (~4%)
```

### Transformer를 SSM과 섞는 하이브리드 구조 부상

순수 대체가 아닌 **Attention 레이어와 SSM 레이어를 교차 배치**하는 방식이 효율 최적점으로 수렴하고 있다.
- NVIDIA Nemotron-H: Mamba:Attention = 7:1
- Ai2 OLMo Hybrid: 동급 Transformer 대비 학습 토큰 49% 절감
CV에서는 아직 검증 단계이나, 긴 시퀀스 처리가 필요한 비디오 분석 등에서 중기적으로 관련성이 생길 수 있다.

### 생성 모델 백본: U-Net → DiT 전환 완료

이미지 생성 모델(Stable Diffusion 계열)이 CNN 기반 U-Net에서 **DiT(Diffusion Transformer)**로 전환했다. Flux.1, Sora, Veo 3 모두 DiT 기반이다. 이미지를 패치 토큰으로 취급해서 Transformer로 처리하는 구조다.

### 추론 시 연산이 새로운 능력 축으로 부상

모델 크기를 늘리는 대신 **추론 시 더 많이 생각하게 하는** 방향이 독립적인 트렌드로 자리잡았다.
- CoT: 추론 과정을 토큰으로 펼치며 forward pass를 반복
- Hidden state 순환: 내부 표현을 반복 정제 (토큰 생성 없이)
같은 모델을 빠른 모드와 깊은 추론 모드로 전환할 수 있어, 엣지 환경에서 실시간성 요구에 따라 품질을 동적 조정하는 방향으로 발전 가능하다.

### 엣지 아키텍처: 적은 RAM으로 큰 모델 운용

- **Gemma 3n (Google, 2025)**: MatFormer 구조로 하나의 가중치 파일에 대·소형 모델을 내포. PLE 기법으로 6.8B 파라미터 모델이 3GB RAM에서 동작.
- **Apple AFM**: KV 캐시 37.5% 절감, 2-bit QAT로 8배 압축.

온디바이스 추론의 실용 가능 범위가 빠르게 확대되고 있다.
