## Context
ML 모델을 설명할 때 혼란이 생겼다. 분류 기준이 여러 개인데 혼용해서이다.
지도 학습 / 분류 / 이상탐지는 각각 다른 축의 개념이다.

## Insights
### 축 1 — 학습 패러다임 (어떻게 학습하나)

| 패러다임    | 핵심 아이디어                             |
| ------- | ----------------------------------- |
| 지도 학습   | 입력-정답 쌍으로 학습                        |
| 비지도 학습  | 정답 없이 데이터의 구조·분포를 학습                |
| 반지도 학습  | 소량 레이블 + 대량 무레이블 혼합 활용              |
| 자기지도 학습 | 데이터 자체에서 정답을 생성 (BERT, MAE, SimCLR) |
| 강화 학습   | 환경과 상호작용하며 보상 신호로 학습                |

#### 반지도 학습은 레이블 수집 비용이 클 때 유용하다  

소수의 레이블된 데이터로 초기 모델을 만든 뒤, 레이블 없는 데이터에 대한 모델의 예측 자체를 "유사 레이블(pseudo-label)"로 삼아 재학습한다.

#### MIL(Multiple Instance Learning)은 반지도 학습과 유사하지만 구조가 다르다 — 약지도 학습(Weakly Supervised Learning)의 하위 개념:

- 반지도: 일부 샘플에 레이블 있음, 나머지 없음
- MIL: 가방(bag) 단위로 레이블을 부여하고, 가방 안 개별 인스턴스에는 레이블 없음

금형 단위로 학습하고 제품 단위로 채점하는 구조가 MIL의 전형적 패턴이다. → [[MIL - 가방 단위 레이블과 인스턴스 단위 추론]]

#### 자기지도 학습 vs 비지도 학습:  

비지도는 정답 신호 없이 데이터 구조(군집, 분포, 압축)를 파악하는 것이 목적이다. K-means, PCA, VAE가 여기 속한다.  
자기지도는 데이터에서 인위적인 pretext task를 설계하고 그 정답을 자동 생성해 지도 학습 형태로 학습한다:

- BERT: 문장의 일부를 마스킹 → 원래 단어가 정답
- SimCLR: 같은 이미지를 다르게 증강한 두 버전 → "이 둘은 같다"가 정답

핵심 차이: 비지도는 정답 신호 자체가 없다. 자기지도는 정답 신호가 있지만, 그것을 데이터 자신에서 추출한다.  
자기지도로 학습된 표현(Representation)은 이후 소량 레이블로 fine-tuning하는 데 쓰인다 — 사실상 반지도 학습의 사전 단계로 기능한다.

#### 강화 학습 — 환경과의 상호작용:  

에이전트(Agent)가 환경(Environment)과 다음 루프를 반복한다:

```
상태(State) 관찰 → 행동(Action) 선택 → 환경이 다음 상태 + 보상(Reward) 반환 → 반복
```

알파고의 경우: 환경 = 바둑판, 에이전트 = 알파고, 행동 = 돌 놓기, 보상 = 이겼다/졌다.  
다른 학습 패러다임과 달리 데이터셋이 없다 — 에이전트가 직접 데이터를 생성하며 학습한다.

### 축 2 — 출력 형태 (무엇을 출력하나)

| 출력 형태               | 설명                    |
| ------------------- | --------------------- |
| 분류 (Classification) | 이산 레이블 (고양이/개, 정상/불량) |
| 회귀 (Regression)     | 연속 수치 (온도 예측, 수율 예측)  |
| 생성 (Generation)     | 새로운 샘플 (이미지, 텍스트 생성)  |
| 순위 (Ranking)        | 우선순위 정렬 (추천 시스템)      |
| 정책 (Policy)         | 행동 선택 확률 (강화 학습 전용)   |

### 축 3 — 응용 태스크 (무엇을 푸나)

동일 태스크를 여러 학습 패러다임으로 접근할 수 있다.

| 도메인    | 대표 태스크                  |
| ------ | ----------------------- |
| 컴퓨터 비전 | 이미지 분류, 객체 검출, 분할, 이상탐지 |
| 자연어 처리 | 번역, 요약, 감성 분석, 텍스트 생성   |
| 시계열    | 예측, 이상탐지, 분류            |
| 추천     | 협업 필터링, 콘텐츠 기반 필터링      |
| 제어     | 강화 학습 계열                |

### 조합으로 표현하기

세 축을 명시하면 모델을 정확하게 기술할 수 있다.

> "비지도 방식(축1)으로 이상탐지 태스크(축3)를 연속 점수 출력(축2)으로 푼다."  
> → PatchCore, Isolation Forest 등

> "지도 학습(축1)으로 결함 유형 분류 태스크(축3)를 다중 클래스 출력(축2)으로 푼다."  
> → EfficientNet-B4 fine-tuning 등
