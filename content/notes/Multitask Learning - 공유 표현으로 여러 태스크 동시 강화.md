## 핵심 원칙
여러 태스크를 **동시에** 학습하여, 각 태스크가 공유 표현을 서로 강화한다.  
하나의 태스크만 학습할 때보다 **일반화 성능이 높아지는 경향**이 있다.

## 구조

```
입력 이미지
      │
[공유 백본]  ← 모든 태스크가 함께 학습
      │
  ┌───┼───┐
[Head 1] [Head 2] [Head 3]
 분류기   검출기   세분화기
  │        │        │
클래스  바운딩박스  픽셀 마스크
```

- 백본(특징 추출기)은 하나, 태스크별 Head는 각자 따로.
- 세 태스크가 동시에 역전파를 보내서 백본을 학습시킨다.

## 왜 동시에 학습하면 더 잘되는가

```
분류 태스크:  "고양이 vs 개" 구분 → 형태, 털 패턴에 집중
검출 태스크:  "어디에 있나"       → 위치, 경계에 집중
세분화 태스크: "정확히 어떤 픽셀" → 세밀한 외곽선 학습

→ 세 태스크가 서로 다른 측면을 강제 학습시켜
  혼자서는 못 배우는 풍부한 표현을 공유 백본이 갖게 된다
```

각 태스크는 서로 다른 관점의 지도 신호를 제공한다.  
이것이 **정규화(regularization) 효과**를 내며, 단일 태스크보다 과적합이 줄어든다.

## Sequential Transfer vs Multitask Learning

```
Sequential Transfer:
  태스크 A 학습 완료 → 태스크 B 학습 시작
  (Catastrophic Forgetting 위험 있음)

Multitask Learning:
  태스크 A + B + C 동시 학습
  (서로가 서로를 잊지 않도록 붙들어 줌)
```

## 언제 효과적인가 / 언제 역효과인가

| 조건                       | 결과                        |
| ------------------------ | ------------------------- |
| 태스크들이 관련 있을 때 (같은 도메인)   | 성능 향상                     |
| 데이터가 부족한 태스크에 다른 태스크가 보완 | 성능 향상                     |
| 태스크들이 무관하거나 충돌할 때        | 성능 저하 (Negative Transfer) |
| 한 태스크의 데이터가 압도적으로 많을 때   | 해당 태스크에 편향                |

<!-- 💡 Negative Transfer: 관련 없는 태스크를 억지로 함께 학습시키면 서로 방해가 된다. 태스크 선택이 중요하다. -->

## 손실 함수 결합

여러 태스크의 손실을 하나로 합산하여 역전파한다.

```
총 손실 = α × 분류_손실 + β × 검출_손실 + γ × 세분화_손실
          ↑ 가중치를 조절하여 태스크 간 균형 설정
```

각 α, β, γ를 어떻게 설정하느냐가 실무에서 중요한 하이퍼파라미터다.

## 실무 사례
- **YOLO / Faster R-CNN**: 분류 + 검출을 하나의 모델에서 동시 학습
- **MT-DNN**: NLP 다중 벤치마크 태스크를 동시 학습한 BERT 변형
- **제조 비전**: 불량 분류 + 불량 위치 검출을 동시 학습
