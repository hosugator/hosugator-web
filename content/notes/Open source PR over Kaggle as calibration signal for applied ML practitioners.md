## Context

외부 교정 없이 능력을 쌓을 때 생기는 자기 평가 불확실성([[Admiration for depth accumulation is social legibility envy not preference mismatch]])을 해소하기 위한 방법을 탐색. 현재 회사 환경에서는 업계 기준 교정 신호를 받을 방법이 없다.

## Insight

### 교정 방법은 실무 프로필과 일치해야 한다

ML 분야의 직접적인 외부 교정 방법은 두 가지다:

- **Kaggle**: 모델·알고리즘 개발 역량을 순위로 측정. 연구/모델링 프로필에 적합.
- **오픈소스 PR**: 숙련된 메인테이너의 코드 리뷰를 통해 업계 기준의 코드 품질 피드백. 개발·패키징·배포 프로필에 적합.

### 역할 정의가 교정 방법을 결정한다

모델과 알고리즘을 직접 개발하기보다 기존 것을 잘 활용·패키징·배포하는 것이 현재 역할에 맞다면, Kaggle 순위는 실무 역량을 반영하지 않는다. 오픈소스 PR 리뷰는 실제 업무와 동형(同形)인 교정이다 — 리뷰어의 코멘트가 머지 여부와 함께 직접적인 피드백 데이터가 된다.

## Decision

Kaggle 대신 오픈소스 기여 → PR 리뷰를 통한 외부 교정을 선택한다.
**이유**: 현재 강점은 모델 개발이 아니라 적용·패키징·배포에 있다. 교정 방법이 실무 프로필과 일치할 때 피드백의 신뢰도가 높다.
**전환 조건**: 모델·알고리즘 개발 비중이 실질적으로 커질 경우 Kaggle을 병행한다.
