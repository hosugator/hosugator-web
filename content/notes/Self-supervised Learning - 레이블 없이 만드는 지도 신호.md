## Context

```
지도 학습:  이미지 100만 장 + 사람이 단 레이블 100만 개 → 비용 매우 큼
비지도 학습: 이미지 100만 장, 레이블 없음              → 뭘 배워야 할지 모름
자기지도:   이미지 100만 장, 레이블 없음, 퀴즈는 스스로 → 레이블 비용 0, 학습 가능
```

인터넷의 텍스트·이미지는 수십억 장이지만 레이블은 극소수다.  
Self-supervised Learning은 이 **레이블 없는 대규모 데이터를 활용**하는 방법이다.
레이블 없이, **데이터 자체의 구조에서 지도 신호를 만들어** 표현을 학습한다.  "정답지 없이 스스로 퀴즈를 만들고 푸는" 학습 방식이다.

## Insights
### 지도 신호를 만드는 방법: Pretext Task

데이터를 **일부러 변형하거나 숨긴 뒤**, 그것을 맞추는 과제(Pretext Task)를 만든다.  
맞추는 과정에서 데이터의 의미 있는 구조를 자연스럽게 학습하게 된다.

#### 텍스트: BERT의 마스킹 (Masked Language Modeling)

```
원문:    "나는 [MASK]를 먹었다"
지도 신호: 정답 = "밥"  (마스킹 자체가 레이블 역할)

모델이 배우는 것:
  "나는" + "를 먹었다" 문맥 → "밥", "점심", "라면"이 어울린다
  → 단어 간 의미 관계, 문법 구조 등 언어의 통계적 패턴
```

레이블을 사람이 만든 게 아니다. 원문에서 단어를 가리는 것 자체가 자동으로 레이블이 된다.

#### 이미지: SimCLR의 대조 학습 (Contrastive Learning)

```
원본 이미지 A
  ├── 변형 1: 밝기 조정 + 좌우 반전  → [벡터 v1]
  └── 변형 2: 색조 변환 + 크롭       → [벡터 v2]

지도 신호: "v1과 v2는 같은 이미지에서 왔으니 비슷해야 한다"
           "다른 이미지의 벡터와는 달라야 한다"

모델이 배우는 것:
  밝기/색조 변화에 무관한 이미지의 본질적 특징
  (물체의 형태, 구조, 텍스처 등)
```

### 학습 과정

```
단계 1 — 사전학습 (Self-supervised):
  대규모 레이블 없는 데이터로 Pretext Task 수행
  → 범용적이고 풍부한 표현(representation) 학습

단계 2 — 다운스트림 태스크:
  학습된 표현 위에 Head만 추가하거나 Fine-Tuning
  소량의 레이블 데이터만 있어도 높은 성능 달성
```

### 대표 모델

| 모델     | 도메인     | Pretext Task                     |
| ------ | ------- | -------------------------------- |
| BERT   | 텍스트     | 마스킹된 단어 맞추기, 다음 문장 예측            |
| GPT    | 텍스트     | 다음 단어 예측 (autoregressive)        |
| SimCLR | 이미지     | 같은 이미지 증강끼리 가깝게 (대조 학습)          |
| MAE    | 이미지     | 마스킹된 이미지 패치 복원                   |
| DINO   | 이미지     | 교사-학생 네트워크 일치 학습                 |
| CLIP   | 이미지+텍스트 | 같은 쌍은 가깝게, 다른 쌍은 멀게 (멀티모달 대조 학습) |

### 멀티모달: CLIP의 학습 데이터 수집 방식

CLIP의 학습 쌍(이미지+텍스트)은 웹 크롤링으로 자동 수집된다. HTML 구조에 이미지와 설명이 함께 존재하기 때문이다.

```html
<img src="cat.jpg" alt="고양이가 소파에 앉아 있는 사진">
<p>고양이는 포유류입니다...</p>
```

이미지 URL + alt 텍스트 + 주변 텍스트를 파싱하면 자동으로 (이미지, 텍스트) 쌍이 만들어진다. 위키피디아, 뉴스, 쇼핑몰 등 수십억 페이지에서 수집 → 사람이 라벨링할 필요 없음.
결과: 텍스트와 이미지가 같은 벡터 공간에 놓이게 되어 텍스트로 이미지 검색이 가능해진다.

GPT 계열 LLM도 결국 Self-supervised Learning으로 사전학습된다. "다음 단어 맞추기"라는 단순한 Pretext Task만으로 언어 전반의 표현을 학습한 것이다.

### Fine-Tuning과의 관계

Self-supervised Learning은 **사전학습 단계의 방법론**이다.  
학습된 표현을 실제 태스크에 적용할 때는 Feature Extraction이나 Fine-Tuning을 사용한다.

```
Self-supervised 사전학습
          ↓
    풍부한 표현 보유 모델
          ↓
Feature Extraction 또는 Fine-Tuning으로 다운스트림 태스크 적용
```
