안드로이드 개발에서 `build.gradle` 파일에 추가하는 "snippet"은 특정 라이브러리, 플러그인, 또는 설정 등을 프로젝트에 적용하기 위한 코드 조각을 의미합니다.
일반적으로 `dependencies` 블록에 라이브러리 의존성 추가: 프로젝트가 해당 스플래시 스크린 라이브러리를 사용할 수 있도록 선언합니다.
```
dependencies {
    implementation("androidx.core:core-splashscreen:1.0.0")
}
```
