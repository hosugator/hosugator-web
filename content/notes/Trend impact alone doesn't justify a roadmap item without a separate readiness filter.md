## Insight

### The four stages narrow from external macro to internal micro, then synthesize into priority

| 단계                            | 관점       | 분석 단위    | 필요 정보                 |
| ----------------------------- | -------- | -------- | --------------------- |
| STEEP + 영향도×불확실성              | 외부 거시    | 트렌드      | 외부 조사만                |
| 전략 적합성(기술연관/영업망/인력)           | 내부 거시    | 장비 카테고리  | 조직 역량 개요              |
| 성숙도×복잡도 + 매력도                 | 내부 미시    | 개별 설비/공정 | 조직 세부 이력(랩 테스트 여부 등)  |
| ACT/READY/WATCH/IGNORE + 타임라인 | 종합(우선순위) | —        | 새 조사 없음, 앞 단계 스코어 종합만 |

앞의 세 단계는 각각 새 축으로 정보를 추가하며 관점을 외부→내부, 거시→미시로 좁혀가는 분석 단계이고, 마지막 단계는 새 정보 없이 앞 단계 스코어를 실행 결정으로 압축하는 종합 단계다. 
이 순서(정보 수집이 싼 것 → 비싼 것)인 이유는, 조직 고유의 세부 데이터가 필요한 비싼 분석(전략 적합성 이후)을 외부 조사만으로 되는 싼 필터(STEEP)로 먼저 좁혀놓은 후보군에만 쓰기 위해서다 — 채용 서류전형→면접, coarse-to-fine 탐지와 같은 깔때기 구조.

### Macro trend scoring only tells you what will happen, not what you should build
- 1단계(메가트렌드): STEEP(사회/기술/경제/환경/정책) 관점을 공정과 설비 축으로 나눠 트렌드 후보를 도출(도메인당 ~10개). 각 요소를 영향도(1~100)×불확실성(1~5, "3~5년 내 확실히 일어날 것인가")로 평가.
- 평가는 단일 인물이 아니라 여러 평가자(개발 임원·컨설팅 담당자)와 도메인별 특화 AI 페르소나를 가중치(예: 20/15/30)로 조합해 편향을 줄인다. "혼자 조사하면 힘드니 AI를 조사·평가에 적극 활용하라"는 게 명시적 지침이었다.
- 영향도가 높은 트렌드 중에서도 불확실성 축으로 다시 갈린다: 핵심 트렌드(고영향+저불확실성=확실히 온다) vs 와일드카드(고영향+고불확실성=오면 파장이 크지만 실현 여부는 불확실).

### A second, independent filter — internal fit, readiness, complexity, attractiveness — decides what actually enters the roadmap
- 2단계(전략 적합성): 살아남은 트렌드를 장비 단위로 치환한 뒤 기술적 연관성 / 기존 영업망으로 접근 가능한 고객 / 인력·제조 역량 3축을 1~5점으로 평가. 평균 3점을 기준으로 핵심/와일드 구분과 교차해 과제 등급을 매긴다.
- 3단계(성숙도×복잡도): 콘셉트만 있음 → 랩 테스트 → 개발 완료 → 양산 가능의 기술 성숙도와, 기존 기술 개선 → 일부 상이 → 구조적으로 상이 → 원리 자체가 다름의 복잡도를 교차해 "개발 용이 / 개발 가능하나 기술적 장벽 / 개발 가능하나 기술+비기술 장벽 / 불확실성 높음"으로 분류한다.
- 4단계(매력도 자체평가): 개발되면 시장이 완전히 재편(사업·기술 가치 모두 높음) → 대체 기술이지만 보통 수준 → 일부만 교체·차별성 부족 → 커머디티 수준을 성숙도×복잡도 결과와 교차해 최종적으로 ACT(즉시 착수) / READY(기술은 있으나 시장이 아직 안 열림, 열리면 진입) / WATCH(기술은 없지만 매력도가 높아 외주·협력사로 개발 관망) / IGNORE(시장성·기술 둘 다 없어 폐기)의 네 버킷으로 분류한다.
- 이 2~4단계가 없으면 "영향도가 높은 트렌드"가 그대로 "우리가 해야 할 일"이 되어버려, 조직의 실제 역량·영업망·기술 축적과 무관한 항목까지 로드맵에 올라간다. 트렌드 스코어와 실행 결정 사이에는 반드시 조직 내부 필터(적합성 → 성숙도/복잡도 → 매력도)를 별도 단계로 끼워야 한다는 것이 핵심.

### The roadmap's real unit is the process step under an equipment, not the trend or the equipment itself
- ACT/READY/WATCH로 남은 장비를 다시 공정 단위로 분해하고, 각 공정 단계별 주요 설비(서브시스템)를 식별한다. 이 공정 단위가 여러 후보 장비에 걸쳐 재사용되면(예: 페이스트 필 공정이 TGV 충진과 핀필 공정에 공통으로 쓰임), 별개로 보였던 항목들이 하나의 개발 과제로 통합된다 — 즉 장비 목록을 그대로 나열하지 않고 공정 재사용성을 기준으로 통합해야 실제 개발해야 할 항목 수가 줄어든다.
- 마지막으로 영업 측의 시장 수요 시점 추정을 얹어 y+1~y+5 축 위에 색상(자체 개발 필요 / 이미 준비됨 / 외주·협력 필요)으로 배치하면, "내년까지 무엇만 준비하면 되는지"가 한눈에 보이는 로드맵이 된다.
