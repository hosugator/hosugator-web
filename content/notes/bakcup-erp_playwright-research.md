## ERP 백업 자동화 옵션 1 상세 분석

이 계획은 외부 ERP 시스템의 복잡한 구조를 정면으로 돌파하기보다는 데이터가 흐르는 통로를 가로채는 지능적인 접근 방식을 취하고 있습니다.


## 주요 기술별 역할 및 프레임워크 설명

- Playwright (브라우저 자동화 도구)
    
    이 도구는 이번 프로젝트의 엔진 역할을 합니다. 사용자가 직접 마우스를 움직이고 키보드를 치는 과정을 코드로 대신 수행합니다. 특히 여러 페이지를 이동하거나 로그인 세션을 유지하는 복잡한 흐름을 관리하는 데 최적화되어 있습니다.
    
- 네트워크 인터셉트 (Network Interception)
    
    이 기법은 이번 자동화의 핵심 전략입니다. 넥사크로와 같은 기업용 프레임워크는 화면 구조가 복잡하여 PDF 버튼을 눌렀을 때 뜨는 팝업창을 제어하기가 까다로운 경우가 많습니다. 이때 화면을 제어하려고 애쓰는 대신, 브라우저 뒷단에서 서버로 전송되는 데이터 흐름을 감시하다가 PDF 파일 데이터가 포착되는 순간 이를 낚아채어 로컬에 저장하는 역할을 수행합니다.
    
- Playwright Codegen (코드 생성기)
    
    이 CLI 도구는 개발 시간을 단축해주는 가이드 역할을 합니다. 브라우저를 열어 직접 로그인하고 클릭하는 동작을 하면 이를 실시간으로 재생 가능한 스크립트 코드로 변환해줍니다. 이를 통해 ERP 사이트의 복잡한 DOM 구조를 일일이 분석하지 않고도 초안 코드를 확보할 수 있습니다.
    


## MCP와 파일 관리의 역할

보고서에서 언급된 Model Context Protocol(MCP)은 AI 에이전트가 홍승완 님의 개발 환경을 더 깊이 이해하고 제어할 수 있도록 돕는 통로입니다.

- mcp-playwright: AI가 실제 브라우저 화면을 들여다보며 현재 어떤 상태인지, 보안 프로그램이 작동 중인지 등을 실시간으로 진단하고 코드를 수정하는 눈 역할을 합니다.
- mcp-filesystem: 자동화 스크립트가 내려받은 수많은 결제 내역 PDF 파일들을 리눅스 파일 시스템 내부에 체계적으로 분류하고 저장하는 역할을 수행합니다.


## 결론 및 권장 실행 단계

보고서의 결론처럼 옵션 1은 효율성이 높지만 보안 플러그인이라는 변수가 존재합니다. 따라서 본격적인 코딩 전에 기술적 가능성을 먼저 타진해야 합니다.

- 우선 우분투 터미널에서 Playwright를 실행하여 ERP 로그인 페이지가 정상적으로 열리는지 확인해야 합니다.
- 만약 키보드 보안 프로그램이나 네트워크 보안 솔루션이 Playwright의 브라우저 제어를 원천 차단한다면, 보고서의 옵션 2인 실제 화면을 캡처하고 마우스 좌표를 계산하는 하이브리드 방식으로 즉시 전환해야 합니다.
