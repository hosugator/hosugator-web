**'골든룰(Golden Rule, 최적 공정 조건)'을 찾는 품질 예측 및 공정 최적화 단계에서는 물리적/수학적 시뮬레이션(CAD, FEM 등) 데이터가 활용되지 않습니다.**

시뮬레이션을 활용한 '모델 기반 접근법(Model-based)'은 부품의 잔여 수명을 예측하거나 고장 메커니즘을 파악하는 **'예지보전(Predictive Maintenance)' 모델을 구축할 때 고장 이력 데이터가 부족한 경우에 한해 제한적으로 사용**됩니다.

#### 모델 기반 접근법 vs 데이터 기반 접근법

두 접근법의 핵심 차이는 '가상 환경이냐 실제 환경이냐'가 아니라, **공식을 먼저 아느냐 vs 데이터에서 공식을 발견하느냐**의 차이입니다.

| 구분 | 모델 기반 (Model-based) | 데이터 기반 (Data-driven) |
|---|---|---|
| **방식** | 물리 법칙·수학 방정식을 먼저 정의하고 적용 | 실제 데이터를 수집한 뒤 통계·ML로 패턴 발견 |
| **예시** | 열전달 방정식, FEM, CAD 시뮬레이션 | 머신러닝, 심볼릭 회귀, 통계 클러스터링 |
| **강점** | 데이터가 적어도 작동. 원인 설명 가능 | 복잡한 현실 변수를 그대로 반영 |
| **약점** | 현실의 모든 복잡성을 공식에 담기 어려움 | 충분한 데이터 없이는 작동 불가 |

→ 제조 골든룰 도출에서는 공정 변수가 너무 복잡해 사전에 공식화가 어렵기 때문에 **데이터 기반 접근**을 채택합니다.

---

그렇다면 가상의 시뮬레이션 없이 PoC(초기 실증) 단계에서 어떻게 무수한 변수들을 통제하고 결품을 예방하는 정상 상태(골든룰)를 찾아내는지, 그 실제 과정은 철저한 **'데이터 기반(Data-driven)' 접근**을 따르며 다음과 같이 진행됩니다.

**1. 실제 파일럿 라인 기반의 A/B 테스트 (수동 운영)** 가상의 환경(시뮬레이션)을 구축하는 대신, 실제 구축된 설비와 실증 파일럿 라인에서 직접 공정 데이터를 수집합니다. 프로젝트 1차년도와 2차년도에는 **'수동 운영 및 A/B Test 검증'** 기간이 배정되어 있습니다. 이 시기에는 작업자와 엔지니어가 직접 개별 변수(온도, 압력 등)를 통제하고 변경해 가며 초기 스냅샷 데이터를 축적합니다.

- *A/B 테스트란?* **하나의 변수만 바꾸고 나머지를 고정**한 채 두 조건(A와 B)의 결과를 비교하는 실험 방법입니다. 웹/마케팅에서는 버튼 색상 A vs B의 클릭률을 비교하는 식으로 쓰이고, 제조 현장에서는 온도 조건 A vs B, 압력 조건 A vs B를 바꿔가며 품질 결과를 비교합니다. 핵심은 단일 변수 통제를 통해 '이 변수가 결과에 진짜 영향을 주는가'를 데이터로 입증하는 것입니다.

**2. 정상 운전 패턴의 통계적/데이터 기반 규명** A/B 테스트로 수집된 초기 시계열 데이터로부터 시간, 통계(평균, 분산, 왜도 등), 물리적 특성(온도 상승률 등)과 같은 주요 Feature(특징)를 추출합니다. 이후 통계적 기법이나 데이터 기반 접근법(시퀀스 모델링 등)을 활용하여 공정 사이클의 반복 패턴을 클러스터링(군집화)하고 분석함으로써, **결함이 없는 가장 이상적인 기준 상태인 '정상 패턴(골든룰)'을 수학적으로 정의**하게 됩니다.

**3. 심볼릭 회귀(PySRRegressor)를 활용한 공식 도출** 초기 테스트 단계에서 사람이 수많은 변수의 상관관계를 일일이 대조하여 완벽한 매뉴얼을 만드는 것은 어렵습니다. 이를 보완하기 위해 축적된 초기 시계열 데이터를 **'심볼릭 회귀(PySRRegressor)' AI 모델**에 입력합니다. 이 AI 모델은 단순 예측을 넘어 데이터 내부의 규칙을 설명하는 **'수학적 표현식(제조 분야 레시피 및 배합 공식)' 자체를 알아서 탐색하고 도출**해 내므로, 초기 골든룰과 최적의 제어 변숫값을 빠르게 확립하는 데 결정적인 기여를 합니다.

**4. 블랙박스 모델(Blackbox Model) 기반의 가상 계측(Virtual Metrology)** 최종적인 품질 예측은 시뮬레이션 공식을 거치지 않고, 공정 파라미터(Input)의 노이즈를 필터링(Kalman Filter 등)한 뒤 곧바로 **딥러닝 기반의 '열성형 공정 모델(Blackbox Model)'에 통과**시키는 방식으로 설계되어 있습니다. 즉, 카메라 등 2D 이미지 특징 추출이나 시계열 분석 역량에 전적으로 의존하여 실시간 품질을 추정(가상 계측)합니다.

**요약하자면,** PoC 단계에서 골든룰을 찾기 위해 가상의 시뮬레이션 데이터를 만들어 테스트하는 것이 아닙니다. **실제 장비에서 수행하는 초기 'A/B 테스트'로 원시 데이터를 모으고, 이를 바탕으로 '통계적 패턴 분석'과 '심볼릭 회귀 AI'를 가동해 데이터 속의 숨겨진 공식(골든룰)을 데이터-드리븐(Data-driven) 방식으로 추출해 내는 것**이 핵심 원리입니다.
