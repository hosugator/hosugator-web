#godaddy #domain #github-page #record #https
godaddy 등 도메인 중개 사이트에서 원하는 도메인을 사서, github pages와 연결하는 프로세스는 아래와 같다.
도메인의 dns record에 github page의 주소를 추가한다. A 레코드에 ip 주소들을 추가한다.
이 때, 기존의 record에 parking 된 A 레코드가 있다면 삭제해야지, 신규 레코드들과 충돌을 발생시키지 않는다.
https 보안 설정이 필수로 자리잡고 있는데, github pages에는 해당 기능을 무료로 제공하기에 pages 설정에서 추가할 수 있다.
