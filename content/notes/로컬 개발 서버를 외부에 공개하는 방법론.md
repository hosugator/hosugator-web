## 핵심 전제

내부 IP(192.168.x.x, 172.x.x.x)는 외부 인터넷에서 보이지 않는다. 같은 네트워크(사내 LAN, 같은 공유기) 안에서만 접근 가능하다. 
외부 공개는 별도 수단이 필요하다.

---

## 방법 비교

| 방법                             | 특징                                           | 적합한 상황          |
| ------------------------------ | -------------------------------------------- | --------------- |
| 터널링 (ngrok, cloudflare tunnel) | 로컬 PC 그대로 노출, 즉시 공개 URL 발급, 무료 플랜은 URL 매번 변경 | 프로토타입 데모, 단기 공유 |
| 클라우드 배포 (AWS/GCP/Azure)        | 공인 IP 고정, 비용 발생, 데이터/모델도 클라우드에 필요            | 실운용, 장기 서비스     |

---

## ngrok 사용법

```bash
ngrok http <PORT>
# → https://xxxx.ngrok.io 형태의 외부 접근 URL 즉시 발급
```

AI 추론 서버처럼 로컬 자원(GPU, 모델 파일)이 필요한 경우 클라우드 마이그레이션 없이 외부 데모가 가능해 프로토타입 단계에 유용하다.

---

## 단계별 전략

1. 프로토타입 단계 → ngrok으로 즉시 데모
2. 현장 배포 결정 후 → 엣지 서버 구성 또는 클라우드 배포 검토
3. 장기 운용 → 공인 IP 고정, 도메인 연결, HTTPS 인증서 구성
