## 핵심 원칙

비지도 이상 탐지 모델(Isolation Forest, Autoencoder 등)은 정상 데이터의 분포를 학습하여, 이로부터 벗어난 패턴을 이상으로 판정한다. 
따라서 정상 운용 중 발생하는 모든 패턴이 학습 데이터에 포함되어야 false positive를 방지할 수 있다.

---

## 문제 발생 구조

제어 시스템(PLC, DCS, SCADA 등)에서는 설정값(Setpoint, SV)이 변경되면 측정값(Process Variable, PV)이 즉시 따라가지 못하고 과도 구간(transient)이 발생한다.

```
SV 변경 시
  SV  ──────┐          (목표값 계단 상승)
            └─────────
  PV  ────────-─╮
				└───── (지연 후 수렴)
	         ↑
    SV-PV 갭 급증 구간 (과도 응답)
```

이 갭이 정상 운용 중 주기적으로 발생함에도 학습 데이터에 포함되지 않으면, 모델은 이를 이상 패턴으로 오분류한다.

---

## 신호 종류별 판단 기준

| 신호 종류 | 전환 발생 빈도 | 학습 데이터 포함 여부 | 이유 |
|-----------|--------------|----------------------|------|
| 주기 내 필연적 전환 | 매 사이클 | 반드시 포함 | 포함하지 않으면 모든 정상 사이클에서 false positive |
| 간헐적 운전 조건 변경 | 드물게 | 포함 권장, 단순화 가능 | 미포함 시 조건 변경 직후 false positive 위험. 초기 Phase에서는 한계로 명시 후 단순화 허용 |
| 설비 초기 가동 (ramp-up) | 시프트 시작 시 | 별도 사이클로 구분 가능 | 정상 생산 사이클과 분리하여 처리 |

---

## 적용 조건

- 모델 타입: 비지도 학습 기반 이상 탐지 (지도 학습이면 레이블로 구분되므로 해당 없음)
- 입력 피처에 SV 또는 제어 출력(MV)이 포함된 경우
- 제어 루프(closed-loop control)가 존재하는 시스템 전반에 적용됨

적용 도메인 예시: 산업 설비, HVAC, 화학 공정, 로봇 관절 제어, 반도체 장비 등 PID/제어 루프 기반 시스템

---

## 합성 데이터에서의 구현 원칙

실제 데이터 수집 전 합성 데이터로 학습하는 경우, 동일하게 적용된다.

- 주기 내 필연적 전환 신호는 물리 모델(1차 지연 등)로 전이 구간 포함하여 생성
- 간헐적 SV 변경을 단순화(고정값)할 경우, 이 단순화로 인해 발생하는 실제 운용 시의 false positive 위험을 문서에 명시해야 한다
