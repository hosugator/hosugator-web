## 개요
제어 시스템에서 설정값(SV) 변경에 대한 측정값(PV)의 응답은 1차 지연(First-Order Lag)으로 근사할 수 있다. 이 모델은 합성 데이터 생성, 시뮬레이션 기반 검증, 예지보전 학습 데이터 구성에 폭넓게 활용된다.

## 연속 시간 모델

```
τ · dPV/dt + PV = SV
```

- `τ` (시상수): PV가 SV의 63.2%에 도달하는 시간
- `τ`가 클수록 응답이 느림 (예: 열 시스템 τ=30~120s, 공압 시스템 τ=0.1~1s)

## 다중 단계 설정값 처리 (V-P Switchover 등)

```python
# 가압 단계: 접근압(2.5 bar) → 가압유지압(6.0 bar) 전환
sv = np.empty(n_samples)
sv[:switchover_idx] = 2.5   # V 단계
sv[switchover_idx:] = 6.0   # P 단계

pv = first_order_lag(sv, tau=0.3, dt=0.01, initial_pv=0.0)
# 전환 시 SV-PV 과도 갭이 자동으로 생성됨 → 정상 패턴으로 포함 가능
```

## 한계
- 실제 시스템은 비선형, 시변(time-varying), 외란(disturbance) 존재 → 1차 지연은 근사
- 제어기(PID) 출력이 포함된 경우, 폐루프 응답은 개루프 1차 지연과 다를 수 있음
- 고차 시스템(2차 이상)은 오버슈트/진동이 있어 1차 모델로 과소 표현됨
