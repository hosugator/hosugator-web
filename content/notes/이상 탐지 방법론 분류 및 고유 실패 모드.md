## 분류 프레임워크 (Ruff et al., 2021)

> Ruff, L., et al. (2021). A Unifying Review of Deep and Shallow Anomaly Detection. Proceedings of the IEEE.

이상 탐지 방법론은 패러다임(What을 학습하는가) × 표현 학습 방식(How를 학습하는가) 두 축으로 분류된다.

### 패러다임 축

| 패러다임 | 핵심 아이디어 | 대표 알고리즘 |
|----------|-------------|-------------|
| One-class | 정상 데이터가 특정 기하학적 경계(구/초평면) 안에 속하도록 학습 | OC-SVM, SVDD, Deep SVDD |
| 확률적 (Probabilistic) | 정상 데이터의 확률 분포를 추정. 저확률 영역 = 이상 | GMM, Normalizing Flows, DAGMM |
| 재구성 기반 (Reconstruction) | 정상 패턴을 재구성(압축 → 복원)하도록 학습. 높은 재구성 오차 = 이상 | Autoencoder, VAE, 1D-CNN AE |

### 표현 학습 축

| 방식 | 특징 |
|------|------|
| Shallow | 집계 피처 또는 원시 피처 직접 사용. 구현 단순, 해석 용이 |
| Deep | 신경망으로 비선형 표현 자동 학습. 복잡한 분포 처리 가능 |

---

## 패러다임별 고유 실패 모드

각 접근법에는 구조적으로 회피하기 어려운 고유 실패 모드가 존재한다. 모델 선택 시 이 실패 모드가 해당 도메인에서 허용 가능한지 판단해야 한다.

| 패러다임 | 실패 모드 | 설명 |
|----------|---------|------|
| One-class | Loose boundary (경계 느슨함) | 데이터 부족 또는 고차원에서 경계가 지나치게 넓어져 이상을 포함 |
| | Hypersphere collapse (Deep SVDD) | 모든 표현을 하나의 점으로 수렴시키는 퇴화 해 발생 가능 |
| 확률적 | Tail fitting 실패 | 분포의 꼬리(극단값) 추정이 부정확하여 희귀 이상을 놓침 |
| 재구성 기반 | Anomaly reconstruction | 모델 표현력이 너무 높으면 이상 패턴도 잘 복원하여 오탐지 방지 실패 |
| | Blind spot | 압축 과정에서 일부 입력 영역이 무시됨 |
| Shallow 공통 | 복잡한 비선형 분포 표현 한계 | 집계 피처에 의존하므로 섬세한 시계열 패턴을 놓칠 수 있음 |

## 실용적 선택 가이드

```
데이터 양이 적다 (수십~수백 샘플)
  └→ Shallow One-class (Isolation Forest, OC-SVM)
     빠른 검증 후 Deep으로 전환

시계열 패턴이 핵심이다
  └→ Deep Reconstruction (1D-CNN AE)
     단, anomaly reconstruction 방지를 위해 bottleneck 크기 조절 필요

Deep + Shallow 결합으로 단점 보완
  └→ 1D-CNN AE (표현 추출) + OC-SVM (경계 결정)
     AE의 blind spot을 OC-SVM이 보완

설명 가능성이 최우선
  └→ Isolation Forest (feature importance)
     또는 Reconstruction AE (per-feature 재구성 오차 맵)
```

---

## PySRRegressor는 이상 탐지 도구가 아니다

PySR(Symbolic Regression)은 데이터에서 수학 공식을 탐색하는 회귀 도구다. "잔차 = anomaly score"로 전용할 수 있으나:

- anomaly score에 확률적·기하학적 근거 없음
- 고차원 다변량 시계열에 단일 수식 탐색은 비현실적
- 이상 탐지의 세 패러다임 중 어디에도 명확히 속하지 않음

→ 설명 가능성 목적이라면 Isolation Forest의 feature importance로 대체 가능
