자바의 메모리 영역은 메소드 영역(Method Area), 힙 영역(Heap Area), 스택 영역(Stack Area)이며, 다음과 같이 분류된다.

메소드 영역은 클래스, 메서드, static 변수 등 설계 정보를 저장하는 공간이며, 클래스 로딩 시점에 생성되고 JVM(Java Virtual Machine)이 종료될 때 소멸된다.
힙 영역은 객체와 인스턴스 변수들을 저장하는 공간이며, 객체가 생성될 때 할당되고 더 이상 참조되지 않는 객체는 GC(Garbage Collector)의 대상이 되어 소멸된다.
스택 영역은 각 스레드별 전용 공간으로 메서드 호출 정보, 지역 변수를 저장하며, 스레드가 시작될 때 생성되어 메서드가 호출될 때마다 해당 메서드의 정보가 스택에 쌓이고(push), 메서드가 끝나면 스택에서 제거된다(pop).
스레드는 자바 프로그램 실행의 주체이며, 스레드가 메서드를 실행하면서, 스택에 기록을 남기고, 설계도(메소드 영역)를 참고하여, 힙에 저장된 객체(구조물)를 만들거나 조작한다.

자바의 참조형 변수는 실제 객체 자체가 아니라 힙 영역에 생성된 객체의 주소(참조값)를 스택에 저장하고, 기본형 변수는 값 자체를 스택에 저장합니다.
참조할 객체가 없는 상태를 null로 표현하며, null 역시 스택에 저장될 수 있습니다.
스택이 과도한 메서드 호출(특히 무한 재귀 호출) 등으로 꽉 찼을 때 StackOverflowError가 발생한다.
