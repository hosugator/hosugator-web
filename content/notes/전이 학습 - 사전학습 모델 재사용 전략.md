## 핵심 원칙
사전학습 모델은 이미 일반적인 특징(선, 텍스처, 패턴)을 알고 있다.  
우리가 할 일은 **그 위에 도메인 지식만 얹는 것**이다.

## 전이 학습의 하위 종류
<!-- 💡 분류 기준: "타겟 레이블이 있는가" + "도메인이 같은가". 각 종류는 별도 노트에서 상세히 다룬다. -->

| 종류           | 태스크   | 타겟 레이블 | 핵심 전략                           | 상세 노트                                           |
| ------------ | ----- | ------ | ------------------------------- | ----------------------------------------------- |
| Inductive    | 다름    | 있음     | Fine-Tuning, Feature Extraction | [[Feature Extraction - 사전학습 표현의 고정 재사용]]        |
| Transductive | 같음    | 없음     | 분포 정렬                           | [[Domain Adaptation - 레이블 없이 도메인 분포 정렬]]        |
| Unsupervised | 다름    | 없음     | 자체 지도 신호 생성                     | [[Self-supervised Learning - 레이블 없이 만드는 지도 신호]] |
| Multitask    | 동시 다수 | 있음     | 공유 백본 멀티헤드                      | [[Multitask Learning - 공유 표현으로 여러 태스크 동시 강화]]   |

## CNN의 레이어 구조와 역할

<!-- 💡 레이어마다 역할이 다르다. 이 계층 구조를 이해해야 "어디까지 얼릴지" 결정할 수 있다. -->

```
입력 이미지
    │
[Conv 하위] ── edge, color, texture 감지 ── 도메인 무관, 항상 재사용
    │
[Conv 상위] ── 부품, 패턴 조합 인식      ── 도메인에 따라 재사용 여부 결정
    │
[FC Layer]  ── 특징들을 종합하여 벡터화  ── 도메인 종속, 보통 교체
    │
[Head]      ── 최종 클래스 결정 경계     ── 태스크 완전 종속, 항상 교체
    │
출력 (클래스 확률)
```

### Conv (Convolutional Layer, 합성곱 레이어)

작은 필터(커널)를 이미지 위로 슬라이딩하며 특징을 추출한다.  
필터가 "세로선 있나?", "곡선 있나?"를 묻고 해당 위치에 값을 남기는 구조.

> 직관: 돋보기로 이미지의 특정 패턴만 집중해서 보는 것.  
> 레이어가 깊어질수록 "선" → "눈" → "얼굴" 순으로 추상화 수준이 올라간다.

### FC (Fully Connected Layer, 완전 연결 레이어)

Conv가 뽑아낸 특징들을 받아 **최종 판단을 내리는** 레이어.  
모든 입력 뉴런이 모든 출력 뉴런과 연결되어 있어서 'Fully Connected'.

### Head (헤드)

FC 레이어를 포함한 **모델의 마지막 출력 구조 전체**를 통칭.  
전이 학습에서는 백본(사전학습 부분)은 두고, **헤드만 교체해서** 다른 태스크에 활용한다.

## LR (Learning Rate, 학습률)

오차를 계산한 뒤 **얼마나 크게 가중치를 수정할지** 결정하는 값.

```
산에서 내려오기 비유:
  LR 큼 = 한 걸음이 10m → 계곡을 휙 지나쳐버림 (발산 위험)
  LR 작음 = 한 걸음이 1cm → 안전하지만 너무 느림
```

<!-- 💡 Fine-Tuning 시 사전학습 가중치를 망가뜨리지 않으려면 LR을 매우 작게 설정하는 게 관례다. -->

**Layer-wise LR Decay**: 하위 레이어일수록 LR을 작게, 상위 레이어일수록 크게 적용.  
이미 잘 학습된 하위 레이어는 조금만, 새로 적응이 필요한 상위 레이어는 좀 더 크게 수정하는 전략.

## Fine-Tuning이 구조적으로 지도 학습인 이유

Fine-tuning의 정의 자체가 "특정 태스크에 적응"이고, 태스크에는 정답(레이블)이 있어야 gradient의 방향이 생긴다.

```
사전학습: 목표 = 언어/지식 이해 → 데이터 자체에서 신호 추출 가능 → 비지도 가능
Fine-tuning: 목표 = 태스크 수행 → "잘했는가"를 측정하려면 정답 필요 → 지도 학습
```

비지도로 Fine-tuning을 하려면 "태스크를 잘 수행했는가"를 레이블 없이 측정해야 하는데, 그게 태스크의 정의상 불가능하다. CPT(도메인 텍스트 추가 학습)처럼 비지도 방식으로 모델을 조정하는 방법도 있지만, 태스크 수행이 아닌 지식 추가가 목적이므로 Fine-tuning이 아닌 추가 사전학습으로 분류된다.

## Fine-Tuning 전략 선택 기준

```
타겟 데이터가 충분한가?
 ├── NO  → Feature Extraction 또는 PEFT (LoRA 등)
 └── YES → 도메인이 사전학습과 유사한가?
            ├── YES → Partial Fine-Tuning (상위 레이어만 unfreeze)
            └── NO  → Full Fine-Tuning (낮은 LR + Layer-wise LR Decay)
```

| 전략                  | Freeze 범위 | 데이터 요구 | 과적합 위험 | Catastrophic Forgetting |
| ------------------- | --------- | ------ | ------ | ----------------------- |
| Feature Extraction  | 백본 전체     | 낮음     | 낮음     | 없음                      |
| Partial Fine-Tuning | 하위 레이어    | 중간     | 중간     | 낮음                      |
| Full Fine-Tuning    | 없음        | 높음     | 높음     | 위험 있음                   |

### Catastrophic Forgetting

Full Fine-Tuning 시 타겟 태스크에 과도하게 적응하여 사전학습 지식이 손상되는 현상.

<!-- 💡 완화 방법: LR warmup, early stopping, EWC(Elastic Weight Consolidation). LR을 처음엔 아주 작게 시작해서 서서히 올리는 것만으로도 상당히 완화된다. -->

## 실무 사례

- **ImageNet → 의료 영상**: ResNet/EfficientNet 백본으로 X-ray 분류 (Partial Fine-Tuning)
- **ImageNet → 제조 이상탐지**: PatchCore는 사전학습 CNN을 Feature Extractor로만 사용, 가중치 고정 → [[이미지 기반 이상탐지 - PatchCore와 메모리 뱅크 패턴]]
- **BERT → 감성분석**: `[CLS]` 토큰 위에 분류 Head만 추가 (Feature Extraction 방식)
