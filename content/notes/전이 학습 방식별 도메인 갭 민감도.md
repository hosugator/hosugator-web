## 핵심 원칙
전이 학습 방식에 따라 도메인 갭을 처리하는 방식이 다르다.  가중치를 고정할수록 두 항이 동일한 편향을 공유하여 도메인 갭이 상쇄된다.

## 방식별 도메인 갭 민감도

| 방식                                | 도메인 갭 처리                   | 강건성     |
| --------------------------------- | -------------------------- | ------- |
| **가중치 고정** (PatchCore 등)          | 비교 두 항이 같은 f(x) 통과 → 편향 상쇄 | 가장 높음   |
| **Linear Probe** (마지막 레이어만 학습)    | 고수준 레이어 편향은 남음             | 중간      |
| **Fine-tuning** (일부 or 전체 가중치 조정) | 학습 도메인 방향으로 가중치 이동         | 출발점에 민감 |

가중치 고정 방식에서 핵심 조건:  
**메모리 뱅크 구성 시와 추론 시의 입력 조건(조명 등)이 동일해야 한다.**  
조건이 달라지면 f(x) 출력 분포 자체가 이동하여 거리 기준이 무너진다.

## 비지도 Fine-tuning의 함정 (이상 탐지 한정)
정상 데이터만으로 fine-tuning하면 **탐지하고 싶은 차이에 오히려 둔감해진다**.

```
Fine-tuning 학습 데이터: 정상 이미지만
        ↓
백본이 배우는 것: 정상 패턴의 공통점 → 정상 내 변동에 둔감해짐
        ↓
결과: 이상 패턴도 정상 클러스터 안으로 수렴
```

이는 이상 탐지의 역설이 아니라 **비지도 학습의 한계**다.  
정상 + 이상 레이블이 모두 있는 지도 학습이라면 fine-tuning이 항상 우월하다.

범용 ImageNet 백본이 좁은 도메인 fine-tuning 백본보다 이상 탐지에 유리한 이유:  
다양한 데이터로 학습된 feature space의 해상도가 높아서, 미세한 시각적 차이도 다른 방향 벡터로 표현된다.

## 유사 데이터 학습이 성능을 보장하지 않는 조건
"학습 데이터가 추론 데이터와 유사하다"는 성능 향상의 **필요조건이지 충분조건이 아니다**.

```
성능 향상 = 유사성 + 충분한 양 + 깨끗한 레이블 + 분포 안정성
```

| 반례 | 메커니즘 |
|------|---------|
| 소량 유사 데이터 | 특정 샘플 암기 → 과적합 |
| 낮은 레이블 품질 | 잘못된 결정 경계 학습 |
| 분포 이동(distribution shift) | 조명·각도 등 미묘한 차이에 과도하게 적응 → brittle |
| 사전학습이 더 풍부할 때 | 좁은 도메인 fine-tuning이 표현력을 오히려 낮춤 |

유사성이 높을수록 모델이 좁은 분포에 강하게 수렴하므로,  
조건이 붕괴되었을 때의 낙폭도 크다.
