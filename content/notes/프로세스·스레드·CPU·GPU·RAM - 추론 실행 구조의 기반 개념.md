## 개념 계층 구조

```
[OS (운영체제)]
    └── 프로세스 A (독립 메모리 공간)
            ├── 스레드 1 (실행 단위)
            ├── 스레드 2
            └── 스레드 3
    └── 프로세스 B (독립 메모리 공간)
            └── 스레드 1
```

---

## 프로세스와 스레드

프로세스(Process): OS가 프로그램 실행에 부여하는 독립 환경.  
자신만의 메모리 공간을 갖고, 다른 프로세스의 메모리를 직접 읽을 수 없다 — OS가 격리한다.  
`python inference.py`를 실행하면 프로세스 하나가 생긴다.

스레드(Thread): 프로세스 안의 실행 단위.  
같은 프로세스의 스레드들은 메모리를 공유한다.  
CPU 코어가 스레드를 실제로 실행한다. CPU 코어 수보다 스레드가 많으면 OS가 빠르게 교대 실행해 동시에 도는 것처럼 보이게 한다(컨텍스트 스위칭).

## RAM, CPU, GPU의 역할 분리

| | 역할 | 특성 |
|--|--|--|
| RAM | 데이터 보관·공급 (창고) | 빠른 읽기/쓰기, 전원 끄면 소멸 |
| CPU | 범용 계산·제어·판단 (관리자) | 코어 수 적음(4~32개), 각 코어가 강력 |
| GPU | 단순 연산 대량 병렬 처리 (조립 라인) | 코어 수 많음(수천~수만), 각 코어가 단순, 자체 메모리(VRAM) 보유 |

CPU가 잘하는 것: 조건 분기(if/else), 반복문, IO 처리, OS 스케줄링 — 순서가 있고 판단이 필요한 작업.

GPU가 잘하는 것: 판단 없이 같은 연산을 동시에 대량으로 수행 — 행렬 곱셈, 픽셀 처리, 물리 시뮬레이션.

---

## 신경망 추론이 GPU를 필요로 하는 이유

신경망 추론의 실체는 행렬 곱셈(Matrix Multiplication)의 연속이다.

```
입력(224×224×3) × 가중치 행렬 → 중간값
중간값 × 다음 가중치 행렬 → 중간값
... (수십 레이어 반복)
→ 최종 출력
```

ResNet-50 기준, 이미지 1장 추론 시 발생하는 곱셈-덧셈 연산: 약 40억 회.

| | 처리 방식 | 속도(이미지 1장) |
|--|--|--|
| CPU (8코어) | 순차 처리 | 30~80ms |
| GPU (3,000코어) | 병렬 처리 | 1~3ms |

행렬 곱셈은 "판단 없이, 같은 연산을, 엄청나게 많이" 하는 작업이다.  
CPU의 강점(복잡한 제어)은 필요 없고, GPU의 강점(단순 연산 병렬)이 완벽하게 들어맞는다.

## CPU 추론 vs GPU 추론의 데이터 흐름

CPU 기반 추론:
```
스레드(작업 지시) → RAM에서 데이터 꺼냄 → CPU 코어로 계산 → 결과를 RAM에 씀
```

GPU 기반 추론:
```
스레드(작업 지시) → RAM → VRAM으로 데이터 이송 → GPU 수천 코어 병렬 계산 → VRAM → RAM(결과 반환)
```

GPU는 스레드를 대체하지 않는다. 스레드가 CPU 코어에게 맡기던 계산 부분을 GPU로 오프로드하는 것이다.  
스레드는 여전히 존재하며 "언제 추론할지, 데이터를 어디서 가져올지, 결과를 어디에 쓸지"를 관장한다.

## 연속 공정에서의 구조 요약

```
모델 객체 (가중치, RAM 또는 VRAM에 상주)
    ├── 스레드 1: [입력 버퍼 A] → CPU/GPU 계산 → [결과 A]
    ├── 스레드 2: [입력 버퍼 B] → CPU/GPU 계산 → [결과 B]
    └── 스레드 3: [입력 버퍼 C] → CPU/GPU 계산 → [결과 C]
```

- 모델 가중치는 read-only → 여러 스레드가 동시에 읽어도 충돌 없음
- 스레드별로 분리되는 것: 입력 버퍼, 중간 계산 버퍼
- CPU만 쓰는 엣지(MCU, 임베디드): 스레드가 RAM ↔ CPU 사이에서 작동
- GPU 있는 엣지(NVIDIA Jetson 등): 스레드가 RAM ↔ VRAM ↔ GPU 사이를 조율

---

## 모델 복잡도에 따른 선택 기준

| 모델 | 연산량 | CPU 충분 여부 |
|------|-------|:---:|
| MobileNetV3, 소형 ONNX | 낮음 | ✓ |
| EfficientNet-B4 | 중간 | 경계선 |
| ResNet-50, ViT | 높음 | ✗ → GPU 필요 |
| 실시간 다중 모델 동시 추론 | 높음 | ✗ → GPU 필요 |
