## 단일 HTML 파일의 한계와 프레임워크 도입
단일 HTML 파일은 내용이 많아질수록 관리와 수정이 복잡하다. React나 Vue 같은 프레임워크는 유지보수성을 크게 향상시킨다. 
프레임워크 사용 경험은 프론트엔드 역량을 효과적으로 어필하는 데 도움이 된다.
## 컴포넌트 기반 개발 방식
프레임워크를 사용하면 웹사이트의 각 부분을 독립적인 컴포넌트로 나눌 수 있다. 
각 컴포넌트는 .vue나 .jsx 파일로 만들어지며, 이 파일 하나에 HTML과 JavaScript, CSS가 함께 포함될 수 있다. 
작성된 코드는 빌드 과정을 거쳐 브라우저가 인식하는 HTML, CSS, JavaScript로 변환된다. 컴포넌트 단위로 나누면 전체 코드가 간결하고 체계적으로 관리된다.
## 공통 스타일 및 상태 관리
모든 컴포넌트에 공통으로 적용될 스타일은 메인 CSS 파일에서 전역으로 관리한다. 컴포넌트의 `<style scoped>` 태그를 사용하면 스타일 충돌을 방지할 수 있다. 언어 전환과 같은 웹사이트의 상태는 Pinia와 같은 중앙 집중식 상태 관리 라이브러리를 통해 관리한다. 하나의 토글 버튼으로 전체 웹사이트의 언어를 동기화할 수 있으며, 한국어와 영어 버전을 별도의 컴포넌트로 만들 필요 없이, 하나의 컴포넌트 내에서 조건부로 렌더링한다.
